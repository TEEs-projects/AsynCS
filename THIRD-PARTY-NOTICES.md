# Third-party notices

The Apache OpenWhisk license and notice files are preserved under
`third-party/openwhisk/`. The WAMR license is preserved under
`third-party/wamr/`. The corresponding patch files contain only the selected
integration changes; deployment inventories and local credentials are omitted.
The independent component repositories preserve the public upstream commit
histories and their original authors. The one added commit in each contains our combined
integration changes. Upstream license and NOTICE files in those source trees
are unchanged from the public base.

The vendored MCL headers retain their upstream README and attribution. The
AsynCS project itself has no license file in the selected source ref; this is a
release blocker and no license is asserted here.
